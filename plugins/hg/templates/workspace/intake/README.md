# intake/: what the department already has

Got a new file? Drop it here and type `/hg:init`, with nothing after it. A link goes in `intake/links.md` first.
Claude reads only what is new and works out what to keep.

This folder stays outside git, so nothing reaches the repo before it has been scanned for personal data
and secrets. Links stay links: the repo keeps a summary and the address, and the original system remains
the source of truth.
